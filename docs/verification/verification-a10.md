## 1. What was built

All new code under `app/src/today/` plus the Today route; nothing outside the FEAT's steps except the four small
enablers listed under "also touched".

- **`app/src/today/model.ts`** — pure model: `vedicDayFor(now, geo, tz)` (civil date, or the previous date before today's sunrise, so the band always holds "now"), `computeToday(self, observer, now, {profiles})` → `{day, panchang, goodHours, note (dailyNote), upcoming, tithiToday, chart}`, `nextBoundaryAfter(gh, now)`, `tithiTodayRows(profiles, day, geo, tz)` (F20 via `janmaTithiFromBirth` + `tithiEventDates` for the current year), `observerFromProfile`. The UI never classifies a segment: every verdict is `engine.goodHours` output.
- **`app/src/today/useToday.ts`** — observer = self profile's place, or the coarse device fix when Settings → Location = "Use my location" (`app/src/location/gps.ts`: `expo-location` foreground permission, last-known-within-30-min else low-accuracy fix, zone via `tz-lookup` → `canonicalZone`; denial/failure → profile place + the caption "Location not available; using <place>"); the model is computed in a `setTimeout(0)` after the first paint (skeleton of hairline boxes, no spinner); `setInterval` 60 s updates the now-marker; a `setTimeout` to the next span boundary (+250 ms) re-renders exactly on the boundary; crossing the next sunrise, a focus return (settings may have changed) or an AppState `active` after a pause recomputes. Language changes do not recompute: the model is language-neutral and components format at render time.
- **`GoodHoursBand.tsx`** (react-native-svg) — ONE 32 dp strip; `<Pattern>` dots (good) / hatch (avoid) from tokens, night spans indigo with the pattern kept in night-ink; day 75 % / night 25 % via the engine's `bandPosition`; hairline dividers between spans; moonrise tick (2 × 7 dp indigo) on the top edge; 2 px ink now-marker spanning the band; now-time label (13 sp accent 600, tabular) above it; tick row sunrise / local noon / sunset / next sunrise (12 sp ink-3 tabular); inline labels per engine `labelFor` (N3) at 13 sp 600, absolutely positioned inside their span and hidden (never clipped) when the span is narrower than 60 dp × fontScale; `accessibilityRole="image"` with the text generated from the same spans (`bandGeometry.ts: bandA11yText`, spans < 60 s skipped). Pure geometry in `bandGeometry.ts` (`spanRects`, `markerX`, `bandLabels`, `tickMarks`).
- **`NowLine.tsx`** — `engine.at(gh, now)` → "Now <time> · <verdict> · <choghadiya> choghadiya · <hora> hora · next: <segment> <time> (<verdict>)" as a `Row` (ruleId = the deciding segment's rule; inputs: applies-now segments, span range, weekday, sunrise, sunset, hora); glossary choghadiya/hora.
