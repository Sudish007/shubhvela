## 5. Deviations from the FEAT text (recorded, not hidden)

- Fonts are copied into `dist/fonts/` from `app/assets/fonts/` at build time; no second copy of the TTFs is committed under `web/public/fonts/` (binary duplication avoided; same output).
- Only two fonts are preloaded per page (Tiro + the body regular of the page's language), not all three families: preloading 2.6 MB of TTFs would compete with the page on mobile.
- OG text is rendered by sharp/libvips (Pango) with the self-hosted TTFs as `fontfile`, not by resvg: resvg 2.6.2 mis-shaped Devanagari (dropped spaces, misplaced matras) on the hi/bho kundli image. resvg renders only the brand mark geometry (`web/public/brand/logo.svg`). `og-base.png` is not used as a compositing base: its text layout changed between the brand run's commits during this step, so the renderer draws mark + Tiro wordmark + rule + title/subtitle/URL itself, in the base's visual language, localised per language.
- CSS is inlined in every page (≈14 KB) and also written once to `assets/site.<hash>.css`; `page(ctx, {inlineCss:false})` links the file instead — for D02's thousands of data pages.
- The home page's counts come from the engine/content tables at build time (331 cities asserted; `{glossary}` = 264 terms and `{lessons}` = 21 injected; fifteen vargas and fourteen activities asserted against the engine constants) instead of the mock's typed "150 terms" / "Twenty lessons".
- The "Today · New Delhi" panel and the city cards print the date they were computed for (the build's Asia/Kolkata civil day; monthly cron); `today-label.js` adds "Today" only when the visitor's date matches. The panchang section heading no longer says "Today's".
